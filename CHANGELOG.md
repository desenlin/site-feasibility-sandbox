# Changelog

All notable project changes are documented here.

## 1.0.0 — 2026-08-31

- Published the framework-free GitHub Pages edition.
- Added parcel and building drawing, vertex editing, moving, rotation, and deletion.
- Added live site area, buildable area, footprint, gross floor area, FAR, lot coverage, open area, FAR capacity, and unused-capacity calculations.
- Added a guided Fullerton learning case and reset control.
- Added hover and keyboard-focus definitions for key concepts.
- Added modular basemap configuration, dual licensing, citation metadata, maintenance documentation, issue templates, and automated Pages deployment.
