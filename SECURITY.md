# Security Policy

## Supported version

The current `main` branch and published GitHub Pages site are supported.

## Reporting a vulnerability

Do not post credentials, personal information, or an exploitable security report in a public issue. Report sensitive concerns privately to `desenlin@fullerton.edu` with the subject **Site Feasibility Sandbox security report**.

For ordinary calculation, display, accessibility, or browser-compatibility problems, use the public bug-report template.

## Data and credential scope

The application is static, stores no accounts or server-side records, and does not transmit student inputs. The repository should never contain API keys, access tokens, student records, or private parcel data.
